================================================================================
                          IMPORTANT NOTES
================================================================================

1. Default Password: All accounts use "password123"
2. Email Domain: All emails must end with @yale.edu
3. User ID 1 (alex.martinez@yale.edu) has special club owner access
4. Data is stored in localStorage (browser-based, not persistent)
5. To reset data: localStorage.clear() in browser console
6. Backend API not required - uses localStorage fallback

7. Status Codes in user.clubs object:
   - 1 = Member (joined via open join)
   - 3 = Pending (application or audition submitted)

8. Club owners need separate owner accounts (sarah.chen@yale.edu, etc.)
   but the system currently uses alex.martinez@yale.edu for demo

9. For production: All passwords should be hashed with bcrypt
10. For production: Use actual backend authentication, not localStorage
